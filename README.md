# Pamoja Stores 🛍️

A modern, highly responsive e-commerce storefront interface built using HTML5, CSS3 (featuring dynamic CSS custom properties for color themes), and vanilla JavaScript. The application utilizes Bootstrap 5 for structural layouts and features real-time search filters, responsive product carousels, and an interactive shopping cart.

## 🚀 Live Features

* **Real-time Search & Filter Engine:** Instantly screens product catalogs by matching text queries, filtering specific category groupings, and sorting prices.
* **Dynamic UI Stock Control:** Evaluates array properties on the fly to flag item availability statuses, disable sold-out interactive targets, and insert badge updates.
* **Stateful Shopping Cart Matrix:** Manages calculations, quantity incremental tallies, interactive item removals, and badge notification updates dynamically.
* **Context-Aware Carousel Overlays:** Intelligently hides promotional banner sliders during search queries to prioritize immediate visibility of relevant search grids.
* **Responsive Contact Form Block:** Includes validation rules, aesthetic floating form inputs, and custom visual info cards matching location configurations.

## 🛠️ Technology Stack

* **HTML5** — Document object model structure and template markup.
* **CSS3 Custom Variables** — Dynamic theme color switching management and layout styling animations.
* **Bootstrap 5** — Fully responsive layouts, grids, spacing alignments, and navigation behaviors.
* **Vanilla JavaScript (ES6+)** — Stateful arrays control, calculation matrices, and DOM update event hooks.
